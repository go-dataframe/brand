# go-dataframe — brand assets

Official logos for the **go-dataframe** organization.

<img src="avatar/go-dataframe.png" width="160" alt="go-dataframe">

The mark is a table: a header row, rows and columns. Its gradient (`#EE8FCF`
to `#A93A82`) is a magenta that sets go-dataframe apart from the emerald of
go-ndarray, go-fft and go-notebook, from go-plot's blue and from go-numerics'
violet; its dark end reads on white at 5.81:1 and its light end on a dark page
at 8.71:1.

## Formats

- **SVG** — `svg/color`, `svg/white` (white, transparent), `svg/black` (black, transparent)
- **PNG** 16→1024 px, 3 variants — `png/<variant>/<size>/`
- **JPG** (color, white background) — `jpg/<size>/`
- **ICO** (Windows) — `ico/`
- **ICNS** (macOS) — `icns/`
- **GitHub avatar** 512 px — `avatar/`
- **Social preview** 1280×640 (repo banner) — `social/`

`check/kit.py` counts the whole matrix on every pull request.
